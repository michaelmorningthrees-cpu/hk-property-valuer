## 🎯 專案定位
HK Property Valuer 是香港首個一站式房地產估價比較平台，整合 HSBC、恒生銀行、花旗銀行、DBS 四大銀行的物業估值數據，為用戶提供免費的估價報告對比服務。

**目標用戶**: 準買家、業主、地產從業員  
**核心價值**: 30 分鐘內獲取四大銀行估價對比報告

## 🧩 核心功能深度解析

### 1. 智能表單系統 (`pages/index.js`)

#### 流程圖
```
用戶選擇地區
    ↓
API: /api/estates?district=長沙灣
    ↓ (返回該區所有屋苑，去重後)
用戶選擇屋苑
    ↓
API: /api/blocks?district=長沙灣&estate=碧海藍天
    ↓ (返回該屋苑所有座數，或「單幢/無座數」)
用戶填寫樓層/單位
    ↓
提交 → /api/valuation
    ↓
寫入 Google Sheets → 後台處理 → 發送郵件報告
```

#### 關鍵技術細節

**A. 每日限額機制**
```javascript
// localStorage 存儲：
// - quotaDate: "Thu Mar 26 2026"
// - remainingQuota: "8" (當日剩餘次數)

// 每日 00:00 自動重置邏輯
useEffect(() => {
  const today = new Date().toDateString();
  const storedDate = localStorage.getItem('quotaDate');
  if (storedDate !== today) {
    localStorage.setItem('quotaDate', today);
    localStorage.setItem('remainingQuota', '10');
    setRemainingQuota(10);
  }
}, []);
```

**B. 服務時間檢測**
- HKT 09:00-22:00: 承諾 30 分鐘內發送
- 其他時間: 報告將於翌日 10:30 前發送
- 實時檢測（每分鐘更新）

**C. 屋苑去重算法** (`/api/estates`)
```
階段一：Unicode 標準化 (NFKC)
    ↓
階段二：異體字統一 ("峯"→"峰", "滙"→"匯")
    ↓
階段三：指紋比對（移除空格/標點，轉大寫）
    ↓
階段四：變種過濾（"樂信大廈" vs "樂信大廈(水街)"）
    ↓
最終結果：按筆劃排序
```

### 2. AI 聊天助理系統

#### 當前狀態：⏸️ 已停用
**停用原因**（推測）:
- 配額控制考量（Gemini Free Tier: ~1,500 次/日）
- 用戶濫用風險（無 CAPTCHA 保護）
- 產品定位調整（專注核心估價功能）

#### 技術架構
```
components/ChatWidget.js (前端)
    ↓ POST /api/chat
pages/api/chat.js (後端)
    ↓ Google Gemini 2.5 Flash API
    ↓ (System Prompt 限制：僅房地產話題)
返回 AI 回應
```

#### 守護規則 (Guardrails)
1. **話題限制**: 拒絕非房地產問題（食譜、編程、政治等）
2. **估價保護**: 不直接給出數字，引導用戶使用網站系統
3. **免責聲明**: 所有金額加註「(僅供參考，以銀行為準)」
4. **隱私保護**: 免責頁面明確警告「勿輸入個人資料」

#### 重啟步驟（如需要）
```bash
# 1. 設定環境變數
echo "NEXT_PUBLIC_ENABLE_CHAT=true" >> .env.local
echo "GEMINI_API_KEY=AIza..." >> .env.local

# 2. 重新部署（Vercel 自動）
git add .env.local  # (本地測試用，勿提交到 Git)
npm run dev

# 3. 驗證功能
# - 檢查聊天泡泡是否出現
# - 測試免責聲明同意流程
# - 監控 API 配額使用
```

### 3. Google Sheets 整合 (`pages/api/valuation.js`)

#### 資料流
```javascript
// 用戶提交 → Next.js API
const payload = {
  action: 'submit_valuation',
  district, estate, estateId, block, floor, flat, email, purpose,
  timestamp: new Date().toISOString(),
  token: process.env.GS_SECRET_TOKEN  // 安全驗證
};

// → Google Apps Script Web App
fetch(process.env.GOOGLE_SCRIPT_URL, {
  method: 'POST',
  body: JSON.stringify(payload)
});

// → 寫入 Google Sheets
// → 觸發後台處理（自動化工具獲取估價）
// → 發送郵件給用戶
```

#### 安全機制
- **Token 驗證**: `GS_SECRET_TOKEN` 防止未授權訪問
- **環境變數檢查**: 啟動時驗證配置完整性
- **詳細日誌**: 所有請求記錄到 Vercel Logs

## 🔐 安全性與隱私

### 已實施措施
✅ **數據保護**:
- 表單數據僅傳送至 Google Sheets（不存儲在 Next.js 服務器）
- 環境變數隔離（`.env.local` 不納入版本控制）
- Token 驗證所有 API 請求

✅ **用戶隱私**:
- 明確的免責聲明和私隱政策
- AI 聊天提示「勿輸入個人資料」
- 承諾「僅發送一次性報告，不打擾」

### 待加強項
⚠️ **Rate Limiting**: 目前僅依賴前端 localStorage（可繞過）  
⚠️ **CAPTCHA**: 無機器人防護（易被濫用）  
⚠️ **API Keys 保護**: Gemini API Key 無 IP 白名單限制

## 🛠️ 開發指引

### 本地環境設置
```bash
# 1. 克隆專案
git clone <repository-url>
cd hk-valuation

# 2. 安裝依賴
npm install

# 3. 配置環境變數
cp .env.example .env.local  # 手動創建
# 填入：GOOGLE_SCRIPT_URL, GS_SECRET_TOKEN, GEMINI_API_KEY

# 4. 啟動開發服務器
npm run dev  # http://localhost:3000

# 5. 構建生產版本（測試）
npm run build
npm run start
```

### 常用開發命令
```bash
# 數據更新
node scraper.js  # 需時 ~30 分鐘，更新 data/*.json

# 數據驗證
node check_hsbc_coverage.js  # 檢查 HSBC 數據覆蓋率

# 調試工具
curl http://localhost:3000/api/debug  # 後端調試端點
```

### 新增屋苑數據流程
1. 執行 `scraper.js` 獲取最新數據
2. 驗證 `data/*.json` 更新成功
3. 測試 `/api/estates` 和 `/api/blocks` API
4. 手動測試表單提交流程
5. 提交更新到 Git（包含新數據文件）
